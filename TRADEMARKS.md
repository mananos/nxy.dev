# Marca y logo

El nombre "nxy.dev" y "nxy", el logo, la mascota (el perro) y todos los archivos de `resources/` son de Matias Nicolas. Todos los derechos reservados.

Estos elementos **no** están cubiertos por la Apache License 2.0, que cubre solo el código. La sección 6 de Apache ya excluye las marcas: la licencia no te da permiso de usar el nombre ni el logo.

## Qué podés hacer

- Mencionar el nombre para referirte al proyecto.
- Linkear al repo.

## Qué no podés hacer sin permiso escrito

- Usar el logo, la mascota o el nombre para otros productos.
- Presentar un fork como si fuera nxy.
- Hacer merchandise con el nombre, el logo o la mascota.

## Si hacés un fork

Sacá la carpeta `resources/` y usá otro nombre y otro logo.

Este texto es una guía simple, no es asesoramiento legal.
